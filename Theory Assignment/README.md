## 🗄️ Assignment 2 — PostgreSQL + JSONB

An interactive web-based assignment exploring **JSONB in PostgreSQL** and how PostgreSQL can provide both relational SQL capabilities and flexible document-style data handling.

### Concepts Covered

- PostgreSQL
- JSONB
- JSON vs JSONB
- Document-Style Data
- JSONB Queries
- JSONB Indexing
- SQL + NoSQL Concepts
- PostgreSQL and MongoDB Comparison
- Express.js
- EJS
- Server-Side Rendering
