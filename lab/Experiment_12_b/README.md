# 🧪 Experiment 12B — Cookies & Sessions in Express.js

## 📌 Overview

This experiment demonstrates **state management in Express.js using cookies and sessions**.

It covers creating, retrieving, and deleting cookies, maintaining user sessions, counting visits, implementing a simple login/logout flow, storing a username in a session, setting cookie expiration, and destroying sessions.

---

## 🎯 Concepts Covered

- Cookies in Express.js
- `cookie-parser`
- `express-session`
- Setting and retrieving cookies
- Deleting cookies
- Session creation and storage
- Session-based visit counter
- Login using sessions
- Logout and session destruction
- Cookie and session expiration
- `httpOnly` cookies
- Form data handling
- Redirects

---

## 💻 Technologies Used

- Node.js
- Express.js
- JavaScript
- `cookie-parser`
- `express-session`
