# 🧪 Experiment 1 — HTML5 Elements & Semantic Web Page

## 📌 Experiment Overview

This experiment demonstrates the implementation of various **HTML5 elements** by creating a complete and responsive Backend Development course webpage.

The webpage combines semantic HTML5 structure, forms, tables, lists, multimedia elements, interactive components, CSS styling, and basic JavaScript functionality.

---

## 🎯 Objective

The objective of this experiment is to understand and implement commonly used HTML5 elements while maintaining:

- Semantic webpage structure
- Accessibility
- Responsive design
- Form handling
- Multimedia support
- Interactive HTML5 components
- Basic client-side interaction

---

## 💻 Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design

# ⚙️ JavaScript Functionality

Basic JavaScript has been added to make the page interactive.

### Range Slider

The displayed experience value automatically changes when the range slider is moved.

### Form Submission

The form submission is intercepted using JavaScript and displays a demonstration success message.

> The form is only a frontend demonstration and does not send data to a backend server.

### Dialog Handling

JavaScript controls the opening and closing of the HTML5 dialog element.

---

# 📱 Responsive Design

The webpage includes responsive CSS using media queries.

```css
@media (max-width: 768px)
```

and:

```css
@media (max-width: 480px)
```

The layout adjusts for smaller devices by modifying:

- Navigation
- Forms
- Tables
- Labels
- Inputs
- Section spacing

The table is also transformed into a mobile-friendly layout on small screens.
