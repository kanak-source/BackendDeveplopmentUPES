# ▶️ Running the Experiments

The method for running an experiment depends on the technology used.

### HTML / CSS / JavaScript Projects

Open the project's `index.html` file directly in the browser or use the **Live Server** extension in VS Code.

### Node.js / Express Projects

Install dependencies:

```bash
npm install
```

Then run the server using the command specified in the individual experiment's README, for example:

```bash
node app.js
```

or:

```bash
node server.js
```
