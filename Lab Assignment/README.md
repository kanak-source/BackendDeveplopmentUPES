- User Login
- Express Sessions
- Authentication Middleware
- Protected Dashboard

- Session Destruction
- Form Handling

## ✅ Assignment 2 — Session-Based To-Do List

A simple To-Do List application where tasks are temporarily stored using **Express Sessions**.
