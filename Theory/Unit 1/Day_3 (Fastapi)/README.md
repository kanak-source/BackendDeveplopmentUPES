# 📖 Theory — Unit 1, Day 3: FastAPI CRUD API

## 📌 Overview

This implementation demonstrates a **Student Management REST API using FastAPI and Pydantic**.

The API supports complete CRUD operations for student records along with branch-based filtering, data validation, response models, and HTTP error handling.

## 📋 Pydantic Models

Two models are used in the application.

### Student

```python
class Student(BaseModel):
    id: int
    name: str
    branch: str
```

### StudentCreate

```python
class StudentCreate(BaseModel):
    name: str
    branch: str
```

`StudentCreate` is used when creating or updating students because the ID is generated by the application.

---

# ⚙️ CRUD Operations

## 📋 Read All Students

```http
GET /students
```

Returns all available students.

The route also supports filtering by branch:

```text
/students?branch=CSE
```

---

## 🔍 Get Student by ID

```http
GET /students/{student_id}
```

Example:

```text
/students/2
```

If the student does not exist, FastAPI returns:

```text
404 Student not found
```

---

## ➕ Create Student

```http
POST /students
```

Example request body:

```json
{
    "name": "New Student",
    "branch": "CSE"
}
```

A new student is added and the API returns:

```text
201 Created
```

---

## ✏️ Update Student

```http
PUT /students/{student_id}
```

Example request:

```json
{
    "name": "Updated Student",
    "branch": "ECE"
}
```

The existing student record is replaced with the updated information.

---

## 🗑️ Delete Student

```http
DELETE /students/{student_id}
```

After successful deletion, the API returns:

```text
204 No Content
```

---

# 🛣️ API Endpoints

| Method | Endpoint | Purpose |
|---|---|---|
| GET | `/students` | Get all students |
| GET | `/students?branch=CSE` | Filter students by branch |
| GET | `/students/{id}` | Get student by ID |
| POST | `/students` | Create student |
| PUT | `/students/{id}` | Update student |
| DELETE | `/students/{id}` | Delete student |

---

## ⚠️ Error Handling

FastAPI's `HTTPException` is used when a student cannot be found:

```python
raise HTTPException(
    status_code=404,
    detail="Student not found"
)
```
