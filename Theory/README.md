# 📖 Backend Development — Theory

This section contains the practical implementations of concepts covered during the **Backend Development Theory** course at UPES.

The content is organized unit-wise and includes implementations using **Node.js, Express.js, Python, Flask, FastAPI, EJS, Jinja2, SQLAlchemy, SQLite, and Pydantic**.

Unit 1 covers the fundamentals of backend development, REST APIs, server-side rendering, and session management.

### Topics Covered

- Express.js & EJS
- Flask REST API
- FastAPI CRUD API
- Express Sessions
- Server-Side Rendering
- Jinja2 Templates
- REST API concepts
- Request & Response handling
